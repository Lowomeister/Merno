# Безопасность

## Как сообщить об уязвимости

Напишите в Telegram: https://t.me/Lowomebot?start=merno (или в Merno: «Связаться с нами» → «Написать в Telegram»), либо закрыто через GitHub: [сообщить об уязвимости](https://github.com/Lowomeister/Merno/security/advisories/new) — такое сообщение видим только мы. Укажите версию Merno и Windows (кнопка «Скопировать сведения»), шаги, как повторить, и что должно было произойти. Пока уязвимость не исправлена, не публикуйте рабочий способ её использования.

## Какие версии исправляются

Только последняя. Перед тем как сообщать, обновите Merno.

## Как Merno защищает обновления

- Каждый выпуск подписан ключом разработчика (RSA): Merno ставит обновление, только если подпись и контрольная сумма файла совпали.
- Данные о выпуске и файлы скачиваются с GitHub Releases этого репозитория по HTTPS.
- Закрытый ключ выпуска и токен бота поддержки не хранятся в репозитории и в программе.

## Что важно знать

- Merno работает с правами администратора и меняет настройки Windows. Скачивайте его только со [страницы выпусков](https://github.com/Lowomeister/Merno/releases) и не запускайте файлы с таким же названием из других мест.
- Выпуски пока не подписаны Authenticode (см. «Подпись кода» в README), поэтому Windows может показать предупреждение.
